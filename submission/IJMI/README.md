# IJMI submission package

Target: **International Journal of Medical Informatics** (Elsevier), **Review article**.
Q1, hybrid (publish free via the subscription track; open access optional, no mandatory APC).

## Files
| File | Purpose |
|---|---|
| `manuscript.docx` | The submission manuscript. Line-numbered, double-spaced (Elsevier refereeing format). Includes Highlights, Keywords, CRediT statement, Declaration of competing interest, Funding. Numbered (Vancouver-style) references, as IJMI uses. |
| `manuscript.pdf` | Reference PDF render of the manuscript. |
| `cover_letter.docx` / `.md` | Cover letter to the Editor-in-Chief. |
| `highlights.docx` | Standalone Highlights file (Editorial Manager uploads Highlights separately). |

Built from `paper.html` via the `html2doc` skill (`review-manuscript` profile). The web
version of the paper lives on GitHub Pages; the reproducibility data/code are on Zenodo
(concept DOI 10.5281/zenodo.21820227).

## Editorial Manager submission notes
- Choose article type **"Review"**.
- Upload Highlights as the separate "Highlights" item (`highlights.docx`); they are also included in the manuscript for convenience.
- Elsevier "Your Paper Your Way": a single line-numbered Word/PDF is acceptable for the initial (refereeing) submission; strict Elsevier formatting is only required at acceptance.

## VERIFY before submitting (placeholders filled with reasonable defaults)
- **CRediT / contributions** — both authors are marked as **equal contributors** (Conceptualization, Methodology, Software, Writing, Supervision), with a byline note "contributed equally to this work." Adjust if not accurate.
- **Funding** — currently "no specific external funding." Update if applicable.
- **Competing interests** — currently "none."
- **Corresponding author** contact details (email, full postal address) — add in Editorial Manager.
- **Suggested / opposed reviewers** — optional, add if desired.
